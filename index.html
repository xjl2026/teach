03｜WorkBuddy功能概览

四类常用能力

READ
读材料
长文、重点、差异、数据
WRITE
写初稿
邮件、纪要、报告、方案
CREATE
做文件
Word、Excel、PPT、网页
CONNECT
接服务
邮箱、文档、会议、网盘
建议：一个任务一个工作空间，相关材料集中放置。
04｜任务模式选择

按任务成熟度选择模式

ASK
查询与讨论
找思路、解释材料，不改文件
PLAN
方案预览
复杂任务先看步骤和范围
AGENT
执行交付
读写文件，生成结果
任务越复杂，越适合先用 Plan；重要文件先保留副本。
05｜移动端与连接能力

离开电脑后，也能继续推进任务

移动端接续

通讯工具助理
微信、企微、QQ、钉钉、飞书
连接器
邮箱、文档、会议、网盘等服务接入
自动化
日报、周报、资料整理等固定任务
06｜适用任务筛选

适合优先尝试的任务特征

高频出现
步骤相近
材料明确
标准清楚
风险可控
示例：会议待办、数据提取、固定格式邮件、周报汇总、报告初稿。

09｜使用合规边界

使用前确认四个问题

信息能否输入？

结果能否外发？

责任如何确认？
提交、判断、发送由人把关
