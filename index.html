03 WorkBuddy能干什么

先记住四个字：读、写、做、接

READ
读
长材料 / 找重点 / 提数据
WRITE
写
邮件 / 纪要 / 报告初稿
CREATE
做
Word / Excel / PPT / 网页
CONNECT
接
邮箱 / 文档 / 会议 / 网盘
一个任务一个工作空间，相关材料放在一起。
04 三种模式

这次是想“问一问”，还是让它“动手做”

ASK
只问
找思路、看材料
PLAN
先看方案
复杂任务先过一遍计划
AGENT
直接执行
读写文件、生成成品
重要文件先留副本；任务越复杂，越值得先开 Plan。
05 几个好用的小技巧

这些功能，平时很容易被忽略

手机远程
人在外面，也能继续给电脑上的 WorkBuddy 发指令。
通讯工具里直接发
微信 / 企微 / QQ / 钉钉 / 飞书。
连接器
邮箱、文档、会议、网盘等按权限接进来。
自动跑
日报、周报、固定整理任务可以定时执行。
